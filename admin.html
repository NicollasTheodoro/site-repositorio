Área restrita. Entre com o seu token de acesso do GitHub para editar o site.

Como gerar o token?
  1. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: "Only select repositories" e escolha site-repositorio.
  3. Permissions → Repository → Contents: Read and write.
  4. Gere, copie o token e cole aqui. Ele só aparece uma vez.
